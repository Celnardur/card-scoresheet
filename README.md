# Card Game Scoresheet

This is the repository for the website [cardscoresheet.com](cardscoresheet.com).
Card Scoresheet helps you keep track of scores, deals, bids, and other stats
for each round of your card game.

## Currently supported Games

- Gin Rummy (In Progress)

## All Local

This website has not ads and is entirely client side. 
It only fetches HTML, Javascript, and assets and doesn't send any data to any servers.

## Architecture

On this website, each card game is it's own single page application.
The main page just has normal links to each card game.
[Mithril.js](https://mithril.js.org/) is used as the reactivity framework
for each card game.
